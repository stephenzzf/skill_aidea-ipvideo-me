# 觅跃科技 IP 视频

版本：1.0.0。觅跃科技品牌视频制作流程，独立维护品牌配置。

## 先确定修改范围

读取用户当前目标、已有视频/脚本/音轨、批准记录与本包 [品牌配置](assets/brand.json)。新内容和局部改版分开处理。默认保持米白、墨绿、哑金信息卡，右下圆形人物、声纹条与“觅跃科技”文字；人物不是主体全屏展示。只换人物或 Logo 时，不改正文、字幕、声音和整体布局。范围以最新用户指令为准。

默认参数和实际尺寸检查见 [视觉规范](references/visual-system.md)。使用本包 `assets/avatar.png`；不得从其他项目悄悄替换角色。它是生成式品牌角色，不是口型同步数字人；Logo 不是像素精确矢量母版。

## 制作新视频

1. **核验选题。** 明确受众、场景和结论。检查官方一手资料，记录发布时间、事件日期、核验日期、适用产品和数字分母。用户简报是待核素材，不自动成为事实。新闻事实、供应商主张、本人实测、原创判断分别标明。规则、价格、模型和关闭日期按当次资料核验。
2. **先找适配的证据画面。** 优先检查相关 YouTube/X 官方内容及可用素材，不为凑片段加入无关演示。按 [证据与媒体记录](references/evidence-and-media.md) 分别记录“内容已核验”“媒体已取得”“复用依据”“可发布范围”。网页可读或有字幕不等于视频已观看。原片无法取得时，方法解读可在目标允许的情况下用明确的原创图解/来源卡；原片动作是核心的案例拆解不能静默替换成卡片。
3. **写口播与分镜。** 首屏直接进入问题；少量解释后清楚收束。口播、屏幕短句、证据和个人建议分开。已有明确试做授权可继续；没有批准且会改变重要内容时，先确认变化部分。不得把历史新闻包装成本周新品，把调查意向说成已实现销量，或把某个人群比例外推到全体。
4. **配音后定时。** 延续用户指定音色。Rami 是本项目的优先音色，不保证所有服务均提供或永久免费。检查当前工具、模型、额度及授权；收费、创建凭据、启用计费与声音克隆不能由 Skill 自行授权。保存原始 WAV 和哈希。仅改视觉，复用原音轨，优先直接复制兼容 AAC 流；不要重配音或拉伸声音凑时长。
5. **按实际声音制作。** 不沿用新稿的旧时间轴。语义字幕避免英文拆词、孤字尾行、过短长句与遮挡；静音/字数估计只能叫近似对齐。信息卡负责解释，来源卡不能冒充截图。声音能量条只是视觉反馈，不是嘴型同步。新内容保持本包视觉形式，而不是新设计一套半身模板。
6. **验收实际导出。** 按 [音频与 QA](references/audio-and-qa.md) 完整解码、查实际编码帧、字幕、首尾、切点、音频和品牌实际尺寸；逐项标记通过/失败/未验证/不适用。技术测量不是完整试听，抽帧不是完整观看，画内边界不是平台 UI 安全验证。
7. **交付并保留版本。** 交付 MP4、必要字幕、来源与真实 QA 边界。指出使用的真实视频片段和仍未核实的许可。生成成片不等于授权公开发布；对外发布遵循本次明确授权。

## 局部修订

只改指定图像/Logo/文字区域；保留上一版并绑定最终输出的检查记录。品牌区尺寸变化先在实际 1080×1920 画面、再在手机缩放下检查。圆内帽子小字仍可能不可读，独立品牌标签不能省略。改视觉时比较同一提取方式的 AAC 哈希；原始帧可比较授权区外零变化，但重新压缩的 MP4 不能承诺逐像素一致。

## 可复用工具

- `python scripts/validate.py`：检查配置、文件引用、头像透明度、品牌尺寸和资源哈希。
- `python scripts/preview.py --font /path/to/chinese-font.ttf --output /path/to/preview.png`：渲染品牌区与字幕占位边界；不生成完整视频，不调用外部模型。
- `python scripts/media_qa.py video.mp4 --compare-audio previous.mp4`：通过本地 FFmpeg 检查流信息、完整解码、音量与可选 AAC 哈希；不替代视觉/听感审查。

运行要求 Python 3.10+，在本目录执行 `python -m pip install -r requirements.txt`；媒体检查另需系统 FFmpeg/ffprobe，预览另需合法可用的中文字体。见 [依赖清单](requirements.txt)、[资源来源](references/asset-provenance.md) 与 [权利边界](LICENSE)。仅运行与当前任务有关的工具。没有可用字体、渲染器、授权音频或视频工具时，说明实际缺项，不把分镜图当作成片。
