# 证据与媒体

先区分任务是视频识别、方法解读，还是案例拆解。识别任务不自动进入制作；案例关键动作缺失时，不用文章摘要偷换为“原片翻译”。

## 每条来源最小记录

- publisher, source_url, publication_date, event_date, checked_at
- claim, supported_scope, limitation, product_or_audience_scope
- evidence_level: metadata / transcript / frames / continuous_video / first_hand_test
- checked_interval, media_local_file（仅项目内相对路径）
- media_status: unavailable / obtained / inspected
- reuse_basis, attribution, intended_use, publication_clearance

来源页面可读、字幕可见、实际观看连续画面分别记录。元数据或摘要不能代替视频本体。需要媒体文件时使用获准原生下载、作者仓库/素材包或用户提供文件；技术失败与明确拒绝不同，不能绕过拒绝。

## 选择和解释

片段要匹配操作者、受众、输入、动作、输出与讲解。品牌相同不代表场景相同。官方演示不证明客户收入、真实后台写入、生产稳定性或本人实测；模拟数据和历史界面要标注。评论是需求线索，不是普遍市场结论。

不能用“公开”“注明出处”“只用几秒”推定有复用或发布许可。按具体许可、作者声明与用途核验；必要时请求授权或改用合法替代。保留必要水印和署名，勿移除来源造成错误归属。发布许可与内容可信度是两项独立检查。

没有可靠连续原片但方法讲解允许替代时，用原创图解＋简短来源标题/日期＋随附完整链接；明确没有使用第三方连续片段。截图、重建界面、原创图解和官方录屏不得混称。

## 时效及数字

记录当前核验日，不把历史文章说成“刚刚发布”。区分发布/弃用/下线/自动路由，明确接口及型号；截止日期已过去不代表已实际调用验证停服。调查人数、人群类型、市场、区间及指标不能混淆；相关性不等于增量因果，可见性不等于访问或订单。
