# 默认视觉系统

## 固定基线与可改范围

画布为 1080×1920、30fps，逻辑坐标 720×1280，缩放 1.5。参数以 `assets/brand.json` 为单一来源。品牌的准确中文为“觅跃科技”；帽侧完整图形与文字、无单独 ME 字母、无白色徽章底，胸前不重复 Logo。角色源图有真正透明通道。

- 信息卡主导；主标题逻辑位置约 (45,211)，正文卡范围 (48,449)–(673,889)，按内容适配。
- 字幕原区域 (43,990)–(548,1140)，最多两行、默认 28 逻辑字号。不得压入品牌区。
- 当前品牌圆：圆心 (625,1040)，半径 65，实际直径 195px。右缘距画布 45px，距字幕右缘 18px。
- 头像源图 1254×1254；裁剪 (180,0,1080,900)，缩放至圆直径的 90%，居中，再圆形蒙版。此参数仅对应随包头像，换图必须重新校准，不能盲目复用。
- 声纹条在圆下，9条；品牌标签在逻辑 (625,1147)，18 逻辑字号、墨绿。声纹随实际音轨驱动；无音轨预览只能标为静态示意。
- 来源两行约 y=1192、1225，进度线 y=1264。不得为了放大头像覆盖来源或字幕。

配色、原尺寸预览和颜色数值均由 JSON 配置管理。平台的按钮、说明文字与安全区因平台而变；上述几何不是通用平台发布安全保证。

## Logo 可读性

帽侧标志是角色识别辅助。全尺寸大图可见，不代表缩成 195px 圆头像后中英文都清晰。必须保留独立“觅跃科技”标签，在实际导出视频和手机缩放下检查。不要以无限放大头像破坏信息卡模板。必须更换品牌母版时，优先用权利明确的原始矢量/高清 Logo，并通过实际尺寸样张确认；生成式重绘不得宣称像素精确。

## 人工检查

检查帽顶、Logo、脸部是否被圆遮罩裁掉；边缘透明是否正确；标签字形是否准确；字幕是否重叠；头部与内容的视觉权重是否合理。只改指定区域时，使用同一时点原/新版原始帧比较；允许范围外应不变，压缩导致的细微差异另行说明。
